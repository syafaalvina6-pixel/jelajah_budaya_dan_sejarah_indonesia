# Jelajah Budaya dan Sejarah Indonesia

Aplikasi Flutter edukasi untuk mengenal budaya dan sejarah Indonesia.

## Fitur
- Informasi budaya Indonesia
- Informasi sejarah
- Jelajah Nusantara
- Game edukasi budaya
- Koleksi budaya

## Teknologi
- Flutter
- Dart

## Tujuan
Membantu pengguna mempelajari budaya dan sejarah Indonesia dengan cara yang menarik dan interaktif.
